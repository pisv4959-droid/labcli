
ЛАБОРАТОРНАЯ РАБОТА № 3. ТЕСТИРОВАНИЕ ПРИЛОЖЕНИЯ

ПОДГОТОВКА ТЕСТОВЫХ ДАННЫХ
Создать файл example.txt со следующим содержимым:
24 -76 81 43 -5


1. ТЕСТЫ ИЗ ТАБЛИЦЫ МЕТОДИЧКИ (Пункт 3.2)

1.1. Генерация с seed
Команда: python mathtool.py fill -c 5 --seed 42
Ожидаемый вывод (stdout): 63 -72 -94 89 -30

1.2. Ошибка количества элементов в fill
Команда: python mathtool.py fill -c 0
Ожидаемый вывод (stderr): ОШИБКА: количество элементов вне диапазона 1..1000000

1.3. Сортировка пузырьком (по возрастанию)
Команда: python mathtool.py sort -m bubble -i example.txt
Ожидаемый вывод (stdout): 
-76 -5 24 43 81
Массив отсортирован.

1.4. Сортировка выбором с записью в файл
Команда: python mathtool.py sort -m selection -i example.txt -o example_sorted.txt
Ожидаемый вывод (stdout): 
Записано элементов: 5 в файл example_sorted.txt
Массив отсортирован.

1.5. Сортировка вставками
Команда: python mathtool.py sort -m insertion -i example.txt
Ожидаемый вывод (stdout): 
-76 -5 24 43 81
Массив отсортирован.

1.6. Сортировка подсчетом по убыванию
Команда: python mathtool.py sort -m counting -i example.txt --order desc
Ожидаемый вывод (stdout): 
81 43 24 -5 -76
Массив отсортирован.

1.7. Двоичный поиск (элемент найден)
Команда: python mathtool.py search -v 43 -i example_sorted.txt
Ожидаемый вывод (stdout): Значение 43 имеет элемент с индексом 4.

1.8. Двоичный поиск (элемент не найден)
Команда: python mathtool.py search -v 15 -i example_sorted.txt
Ожидаемый вывод (stdout): Значение 15 не найдено.
Код возврата: 1

1.9. Двоичный поиск (массив не отсортирован)
Команда: python mathtool.py search -v 43 -i example.txt
Ожидаемый вывод (stderr): ОШИБКА: массив не упорядочен по возрастанию
Код возврата: 1


2. ДОПОЛНИТЕЛЬНЫЕ ТЕСТЫ СОРТИРОВОК (Крайние случаи)

2.1. Массив из одного элемента
Создать файл one.txt с содержимым: 10
Команда: python mathtool.py sort -m bubble -i one.txt
Ожидаемый вывод: 10
Массив отсортирован.
Команда: python mathtool.py sort -m insertion -i one.txt --order desc
Ожидаемый вывод: 10
Массив отсортирован.

2.2. Массив с повторяющимися элементами
Создать файл repeats.txt с содержимым: 5 5 5 2 2 8 8
Команда: python mathtool.py sort -m selection -i repeats.txt
Ожидаемый вывод: 2 2 5 5 5 8 8
Массив отсортирован.

2.3. Уже отсортированный массив
Создать файл sorted.txt с содержимым: 1 2 3 4 5
Команда: python mathtool.py sort -m bubble -i sorted.txt
Ожидаемый вывод: 1 2 3 4 5
Массив отсортирован.

2.4. Обратный порядок
Команда: python mathtool.py sort -m counting -i sorted.txt --order desc
Ожидаемый вывод: 5 4 3 2 1
Массив отсортирован.


3. ТЕСТЫ ОШИБОК И ВВОДА С КЛАВИАТУРЫ

3.1. Ввод с клавиатуры (через запятую и пробел)
Команда: python mathtool.py sort -m bubble
Ввод: 5, 3, 1, 4, 2
Ввод: (нажать Enter для завершения)
Ожидаемый вывод: 1 2 3 4 5
Массив отсортирован.

3.2. Некорректные границы в fill
Команда: python mathtool.py fill -c 5 --min -200 --max 10
Ожидаемый вывод (stderr): ОШИБКА: некорректные границы значений

3.3. Превышение лимита поиска (MAX_SEARCH = 1000)
Команда: python mathtool.py search -v 2000 -i example_sorted.txt
Ожидаемый вывод (stderr): ОШИБКА: искомое значение по модулю не должно превышать 1000

3.4. Ввод букв вместо чисел в массиве
Команда: python mathtool.py sort -m bubble
Ввод: 1 2 abc 4
Ожидаемый вывод (stderr): ОШИБКА: элемент массива не является целым числом


4. ТЕСТЫ ПРЕДЫДУЩИХ РАБОТ (Проверка, что ничего не сломалось)

4.1. Решение квадратного уравнения
Команда: python mathtool.py solve -a 1 -b -3 -c 2
Ожидаемый вывод: Уравнение квадратное
D = 1
x1 = 2.000
x2 = 1.000

4.2. Сумма ряда
Команда: python mathtool.py series --func third --terms 5
Ожидаемый вывод: S = 1/3 - 1/6 + 1/9 - 1/12 + ...
Слагаемых: 5
Сумма ряда: 0.2833

4.3. Интегрирование
Команда: python mathtool.py integrate --func root --from -1 --to 1 --steps 100
Ожидаемый вывод: F(x) = sqrt(x^2 + 1)
Значение интеграла: 2.2370


5. ЗАМЕРЫ ВРЕМЕНИ (Пункт 3.3)

Создание файлов:
python mathtool.py fill -c 1000 --seed 1 -o size_1000.txt
python mathtool.py fill -c 3000 --seed 1 -o size_3000.txt
python mathtool.py fill -c 10000 --seed 1 -o size_10000.txt

Запуск сортировок (выполнить по 3 раза для каждого размера и метода, время операции смотреть в stderr):
python mathtool.py sort -m bubble -i size_1000.txt -o out_bubble_1000.txt
python mathtool.py sort -m selection -i size_1000.txt -o out_selection_1000.txt
python mathtool.py sort -m insertion -i size_1000.txt -o out_insertion_1000.txt
python mathtool.py sort -m counting -i size_1000.txt -o out_counting_1000.txt

(Повторить аналогично для size_3000.txt и size_10000.txt)
